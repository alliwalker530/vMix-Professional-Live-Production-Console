## Features

- Multi-camera and input configuration guides for capture cards and NDI

- Audio mixing and routing workflow examples
- Streaming destination presets for YouTube, Facebook, Twitch and custom RTMP
- Recording, replay and virtual set workflow documentation
- Step-by-step tutorials covering inputs, layers, transitions and shortcuts
- Real-world examples demonstrating efficient live production workflows

## Usage

Open the extracted folder and explore the template and guide directories. Import the included project templates and overlays directly into vMix or follow the documentation to configure cameras, audio, streaming destinations and recording settings. The guides provide practical instructions for each resource.
